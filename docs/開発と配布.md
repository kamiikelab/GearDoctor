# 開発と配布

ソースは一つ（Dart / Flutter）です。配布先だけが違います。

| | Android | iPhone |
| --- | --- | --- |
| 資料 | [開発と配布（Android）](開発と配布-Android.md) | [開発と配布（iPhone）](開発と配布-iPhone.md) |
| ビルド | 手元の `./scripts/build_apk.sh` | Codemagic の IPA |
| 配布 | [GitHub Releases](https://github.com/kamiikelab/GearDoctor/releases) の APK | App Store Connect → TestFlight / App Store |
| 出さないもの | Google Play | GitHub Releases |

どちらも、テストは手元と GitHub Actions の `flutter test` です。画面の最終確認は実機です。Linux の窓はスマホの代わりになりません。
