# フランス語対応

日本語・英語にフランス語を足して、3か国語にする。ストアの掲載と、アプリの中の両方を含む。

チェックは、フランス語にしたビルドを手元で動かして付ける。文言の正本はこの文書である。表現を変えるときは、実装の前にここを書き換える。

日付の表示は `YYYY-MM-DD` のままにする。単位 `km`、位置の `F` / `R`、アプリ名 `GearDoctor` も変えない。すでに入っている自転車名・部品名・メモは、言語を切り替えても書き換わらない。フランス語の初期データは、新規インストールか「初期状態に戻す」のあとに入る。

Android は同じアプリになる。Google Play の掲載は作らない。

## 言語の切り替わり

- [ ] 設定の表示言語が「端末に合わせる」「日本語」「English」「Français」の4つである
- [ ] 「Français」にすると、この文書の画面確認がすべてフランス語になる
- [ ] 「日本語」「English」は、いままでどおりその言語になる
- [ ] 端末の言語がフランス語（フランス、ベルギー、カナダなどを含む）で「端末に合わせる」のとき、フランス語になる
- [ ] 端末の言語が日本語のままのとき、フランス語にはならない
- [ ] 言語を切り替えても、すでに保存した自転車名・部品名・交換メモは変わらない
- [ ] 「初期状態に戻す」のあと、そのときの言語でデモが入る

## 画面

各画面をフランス語で開き、ボタン、見出し、助けの文、確認ダイアログに日本語と英語が残っていないこと。

- [ ] ホーム（デモ案内、ギア、走行の範囲、しきい値、部品カード、走行を追加）
- [ ] 部品の詳細（状態、交換した、編集、過去の交換記録）
- [ ] 交換を記録（日付、メモ、記録、履歴）
- [ ] 記録を編集（保存、削除、キャンセル）
- [ ] ギア（自転車の追加と削除、部品の追加、2つの CSV、表示のまとめ）
- [ ] 自転車を追加
- [ ] 部品の追加と編集（登録名、周期、目安、しきい値、削除の確認）
- [ ] 表示のまとめ（まとめる、分ける。左が R、右が F の説明）
- [ ] 走行を追加（手入力、Strava の取得、期間、開始日の変更）
- [ ] 走行を確認と走行を編集（種類は手入力 / Strava / デモ）
- [ ] 設定（言語、ユーザー説明、初期化の確認、版、プライバシーポリシー）
- [ ] Strava 連携（状態、連携、解除、手順）
- [ ] 交換記録の CSV
- [ ] 部品登録の CSV
- [ ] 日付の選択ダイアログがフランス語である（表示の日付形式は `YYYY-MM-DD` のまま）
- [ ] ユーザー説明を「なし」にしても、フランス語の短い表示が欠けない

## デモの自転車と交換メモ

初期状態のロード側だけを見る。メモが付くのは前タイヤの1件と後タイヤの1件である。

- [ ] 自転車名が Route、Cyclo-cross、Vélo CLM である
- [ ] 前タイヤの交換メモに Remplacé après une crevaison がある
- [ ] 後タイヤの交換メモに Entaille du flanc がある
- [ ] ほかのデモ交換メモは空のままである

## 名前から付く交換目安

部品を新規追加し、登録名だけで推奨の距離または月が入ること。アクセントの有無はどちらでも同じ目安になる。

- [ ] 名前に pneu で 6000 km
- [ ] 名前に chaîne または chaine で 4000 km
- [ ] 名前に plaquette で 1500 km
- [ ] 名前に câble または cable で 5000 km
- [ ] 名前に liquide または huile で 10000 km
- [ ] 名前に disque で 8000 km
- [ ] 名前に guidoline または galet で 5000 km
- [ ] 名前に pile で 12 か月
- [ ] 日本語名（タイヤ、電池など）と英語名（tire、battery など）の目安は、いままでどおり付く

## CSV

書き出しの見出しとセルの言葉は、そのときの表示言語になる。取り込みは日本語・英語・フランス語のどれでも受ける。`F` と `R` は変えない。

- [ ] 交換記録の見出しが `Nom enregistré,Date,Mémo` である
- [ ] 部品登録の見出しが `Nom enregistré,Intervalle,Objectif,Défaut,Personnalisé,Seuil,Groupe,Position` である
- [ ] 周期のセルが `Distance` または `Mois` である
- [ ] 目安のセルが `Défaut`、`Auto`、`Personnalisé` のどれかである
- [ ] 「例を入れる」が、上のフランス語の部品名と見出しになる
- [ ] フランス語で書き出した CSV を、そのまま取り込める
- [ ] いまの日本語 CSV と英語 CSV も、フランス語表示のまま取り込める
- [ ] 壊した CSV のエラー文がフランス語である

## エラー文

通常の操作では出ないものも含め、利用者に見える文を3言語にする。

- [ ] デモ中に部品の追加や CSV を開くと、フランス語で止められる
- [ ] Strava の失敗、認可の失敗、走行や部品の操作で画面に出る文がフランス語である
- [ ] ソース内の利用者向けメッセージに、日本語だけの固定文が残っていない

## プライバシーポリシー

`docs/privacy-policy.html` にフランス語を足す。内容は日本語・英語と同じにする。施行日は 2026年9月6日のまま（フランス語では 6 septembre 2026）。

公開 URL は `https://kamiikelab.github.io/GearDoctor/privacy-policy.html`。

- [ ] ページ上部に 日本語、English、Français がある
- [ ] `?lang=fr` でフランス語の本文が出る
- [ ] ブラウザの言語がフランス語のとき、パラメータ無しでもフランス語が出る
- [ ] 日本語と英語の出し分けは、いままでどおりである
- [ ] アプリの設定から開くと、表示がフランス語のときは `lang=fr` になる
- [ ] 1. 基本方針に相当する節がある
- [ ] 2. 端末の中に残す情報に相当する節がある
- [ ] 3. 外部に送る情報に相当する節がある
- [ ] 4. 以降、日本語版の最後の節まで欠けがない
- [ ] 公開 URL で、上と同じ表示になる

## App Store

新しい版のバイナリにフランス語を含め、商品ページの言語が English、Japanese、French の3つになること。掲載文だけ先に出して、アプリが英語のままにしない。

- [ ] フランス語のアプリ名は GearDoctor のままである
- [ ] サブタイトル、説明、キーワード、プロモーション用テキスト、最新情報の文がフランス語である
- [ ] スクリーンショットを、フランス語の画面で、いま店頭に出しているのと同じ画面・サイズで撮り直している
- [ ] プライバシーポリシーの URL は同じである
- [ ] 商品ページの言語が English、Japanese、French である
- [ ] フランスのストアで、説明とスクリーンショットがフランス語である
