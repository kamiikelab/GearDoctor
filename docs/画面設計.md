# 画面設計

色や装飾は後回しです。確認用のワイヤーフレームはチャット横の Canvas にあります。ソースは [`canvases/ui-wireframe.canvas.tsx`](../canvases/ui-wireframe.canvas.tsx) です。

## 決まったこと

- 下部タブは置かない
- 「交換した」は詳細画面だけ
- 詳細の「交換した」ボタンの下に、その部品の過去の交換記録を出す（ギアの走行距離・交換日・コメント）。ギアの走行距離はそのギアの最初の走行日からの積算。交換日に走行がなくても、その日までの積算を出す。一番下は今日までの積算で、距離に（今日）を付け、交換日は空欄
- 交換日は初期値を今日にし、記録し忘れのときは別の日に直せる
- 「交換した」画面では、記録ボタンの下にも同じ過去の交換記録を出す
- 交換記録には任意のコメントを付けられる。履歴表にも出す
- 過去の交換記録は行をタップして、日付の修正・コメントの修正・削除ができる
- ホームで一番大きいボタンは「走行を追加」。押すと走行画面へ切り替える
- 走行の入れ方は二つ。同じ画面の上が手入力、下が Strava から取り込む。同じギアでも混ぜてよい
- デモのあいだは両方使える。最初の実走行でデモ走行は消える。そのあとも両方使える
- 「走行を確認」の表に種類（手入力 / Strava / デモ）を出す。タップして直す・消せるのは手入力だけ。表の大きさは交換記録と同じ
- 取り込みで手入力は消さない。Strava の走行は参照だけ
- Strava からの取得は自動では行わない。連携済みのときだけ、「前回から 1 年」で取りに行く
- Strava から取り込む期間は、前回から 1 年。Strava開始日はアカウント1本の取得の左端
- ギアの開始日は置かない。部品の起点はそのギアの最古走行。最古を前にしたいときは、そのギアに古い手入力を足す
- 何日までは、Strava開始日以降で入っているいちばん新しい走行の日（同期した日ではない。手入力も含む）
- Strava開始日を変えると、取り込んだ Strava を消す。手入力は残す。この操作では取得しない。「前回から 1 年」で新しい日から取り直す
- 最初の部品はタイヤ、チェーン、ブレーキパッド、ワイヤー、ブレーキオイル、ディスク、バーテープ、センサ・ライトの電池、プーリー
- 交換周期は距離（km）か月、部品ごとにどちらか一方。日指定はしない。しきい値は選んだ周期に対する％。距離と月を切り替えると、設定の値は新しい推奨と同じ値に戻す
- 部品は登録名だけで管理する。追加に単独 / F / R の種別は付けない
- 左右の合体は表示のまとめだけ。まとめた名前は表示専用で、登録名とは合わせない
- ホームでスクロールするのは部品一覧だけ。警告と「走行を追加」は固定
- デモ走行があるあいだ、ホームの GearDoctor 直下に「デモを解除するには走行を追加します」を出す。しきい値バナーと同じ枠。タップで走行画面。手入力か Strava からの最初の実走行でデモ走行は消える
- デモのあいだは部品の追加・削除と CSV はエラーにする。「先に走行を追加してください」と出す。実走行が入るまで入れられない
- 「部品を追加」「交換記録の CSV」「部品登録の CSV」「表示をまとめる / 分ける」はギア画面の中。ホームのギア名（緑の枠ボタン）をタップして開く
- Strava の連携は走行を追加の画面から専用画面を開く。連携は任意で、その画面に書く。連携方法の説明は「連携を解除」の下。走行を追加はホームの主ボタンから。ギアはホームの緑の枠ボタンから
- 設定の「初期状態に戻す」は確認のうえ、Strava の連携と走行、部品の設定と交換記録を消し、初回と同じデモ状態に戻す
- 設定のいちばん下に `GearDoctor 1.0.0` を出す。APK を作るたびに版を 0.0.1 ずつ上げる
- 部品を追加したときの最初の交換日は、選んでいるギアのいちばん古い走行日。入力欄は置かない。走行がまだ無いときは今日
- その日の始まり（0:00）を起点にする。同じ日の走行は距離に入り、その日自体も期間の初日になる
- 前提は、そのギアで走り始める前に部品を最新にしていた、こと。最初の走行日＝いま乗っている部品の起点
- Strava開始日（いつから取るか）と、部品の起点（そのギアの最初の走行日）は別。部品の距離・月・自動周期は後者を使う
- 交換記録はギアごと。部品の設定・追加・表示のまとめもギアごと。初期の部品は同じ。自転車は手で足せる。手で足した自転車とデモの自転車は消せる（最後の1台も可。デモ中も可）。Strava から取った自転車はここでは消せない。Strava から取った自転車も同じ一覧に出る。ギアを選んでから、CSV と交換記録が使える
- 部品の削除は編集画面。デモ解除後なら初期の18件も消せる。消した初期部品は起動しても戻さない
- 交換記録の CSV は、選んだギアの記録だけを出し入れする。既存の登録名にだけ取り込む。書き出しも同じ形式。部品は作らない。交換日は `YYYY/MM/DD`。以前の `YYYY-MM-DD` も取り込める。交換日が空の行は、そのギアの最初の走行日（まだ無いときは今日）。CSV に出てきた登録名は、そのギアのいまの交換記録を消して差し替える。他のギアの記録はそのまま
- 部品登録の CSV は、選んだギアの部品設定だけを出し入れする。列は 登録名,周期,目安,推奨の値,設定の値,しきい値,まとめ,位置。無い登録名は部品を足す（最初の交換日はそのギアの最古走行日）。CSV に出た部品の設定とまとめを差し替える。交換記録と、CSV に無い部品はそのまま。並び順は出さない
- しきい値の警告は件数と、タップできる名前の並び。1件でも同じ形
- 走行距離の集計対象ギアは、ギア画面で選ぶ。手で足した自転車でも、Strava から取った自転車でもよい
- デモの自転車はロード、シクロクロス、TTバイク。メーカーの車名は使わない
- ホーム上部は「ギア: ロード」を緑の枠ボタンにし、右に走行の範囲を2行で出す（そのギアの最古〜 / 最新）。幅が広くても1行にまとめない。ギアボタンは文字幅に合わせる。ギアはタップでギア画面。走行の範囲はタップで走行画面
- 初回のデモ走行・デモギアがあるあいだは、ギア名・走行の範囲・距離の値の末尾に「（デモ）」を付ける。月の経過には付けない。最初の実走行でデモ走行が消えると印も消える
- 交換目安は推奨、自動、設定の三択。進捗に使うのは選んだ一方。自動は毎回、記録と走行から計算する。交換が2回以上なら直近とその一つ前のあいだ。1回だけなら、そのギアの最初の走行日からその交換まで
- ホームの距離・か月は、使った量 / 交換目安と種別（推奨 / 自動 / 設定）を出す
- 走行画面の下段は、Strava開始日と何日までの両方を出す。連携の前後でボタンの数は変えない。未連携のときは「前回から 1 年」だけ灰色。「連携は任意です」と Strava 連携への案内を同じ画面に出す

## ホームのイメージ

前後がある部品は、自転車を左から見て右が進行方向、という向きです。左が R、右が F。左右は別々にタップして詳細へ進みます。

```
GearDoctor                          設定
デモを解除するには走行を追加します。 ← デモ中だけ。タップで走行画面
[ ギア: ロード（デモ） ]     走行 2023-04-15〜
                             2026-07-15（デモ）
        ↑ 緑の枠。タップでギア画面         ↑ 2行。タップで走行画面

しきい値 2件
[タイヤ F]  [ブレーキパッド F]   ← タップで詳細へ

        ↑ ここから下の部品だけスクロール
┌ タイヤ                                        ┐
│ R：余裕・45％          │ F：そろそろ・80％     │
│ 2,700 / 6,000 km 推奨（デモ） │ 4,800 / 6,000 km 推奨（デモ） │
│ ████░░░░               │ ████████████░░        │
└───────────────────────────────────────────────┘
┌ チェーン                                      ┐
│ 余裕・45％                                    │
│ 1,800 / 4,000 km 推奨（デモ）                  │
└───────────────────────────────────────────────┘
┌ ブレーキパッド / ワイヤー / ブレーキオイル / ディスク もタイヤと同じ左右   ┐
┌ スピードセンサ電池                            ┐
│ 余裕・58％                                    │
│ 7 / 12 か月 推奨                              │
└───────────────────────────────────────────────┘
        ↓ ここまで
[        走行を追加        ]   ← 固定
```

まとめ表示のカードは表示名（例: タイヤ）で、左が R、右が F です。分けて表示すると、各カードは登録名（例: 前タイヤ、後タイヤ）で出ます。記録は独立したままです。登録名と表示名に差ができても、自動では合わせません。

チェーンは単独なので、まとめません。

## 交換を記録

初期値は今日です。記録し忘れのときは、交換日を実際の日に直してから記録します。距離はその日以降の走行から数え直します。

```
戻る                    交換を記録

タイヤ（F）を交換した日付を記録すると、
この位置の走行距離だけゼロから始まります。

交換日
[ 2026-08-23 ]          ← タップして修正
初期値は今日。記録し忘れのときは実際の日に直す

メモ
[ 製品名、交換理由など（空でも可） ]

[ 記録する ]

過去の交換記録   ← 行をタップして編集
ギアの走行距離     交換日       コメント
5,800km（デモ）   2023-04-02  —
11,900km（デモ）  2024-01-15  パンク後に交換
16,700km（デモ）  2025-03-01  —
21,500km（今日）

[ キャンセル ]
```

記録を編集:

```
戻る                    記録を編集

タイヤ（F） · 4,800 km

交換日
[ 2025-03-01 ]

メモ
[ パンク後に交換 ]

日付を変えると、その期間の走行距離を数え直す

[ 保存 ]
[ この記録を削除 ]
[ キャンセル ]
```

## 部品を追加

ギア画面から開きます。ギアを選んでいないときは追加できません。追加は常に1件で、付けるのは登録名だけです。単独 / F / R の種別はありません。左右を1カードに見せるのは「表示のまとめ」です。

```
登録名
[ 前タイヤ                  ]
```

交換周期は距離か月の二択で、同時には使わない。距離と月を切り替えると、設定の値は新しい推奨と同じ値に戻す。

```
交換周期
[ 距離 ]  [ 月 ]
```

月を選んだ例（スピードセンサ電池）:

```
交換目安
┌ 推奨  12 か月 ┐
┌ 自動  — ┐
┌ 設定  12 か月 ┐
```

距離を選んだ例（ブレーキオイル）:

```
交換目安
┌ 推奨  10,000 km ┐
┌ 自動  8,200 km ┐
┌ 設定  10,000 km ┐
```

編集では、保存の下に「この部品を削除」を出します。デモ中は先に走行を追加してください。デモ解除後は初期の18件も消せます。消した初期部品は起動しても戻しません。

## 交換目安

追加・編集で、推奨・自動・設定を並べて一つを選びます。三つの数値は常に見えます。進捗に使うのは選んだ一方だけです。ホームと詳細の距離・か月には、使った量 / 交換目安と種別（推奨 / 自動 / 設定）を出します。自動は毎回、交換記録と走行から計算します。保存した固定値ではありません。交換が2回以上あれば、直近とその一つ前の交換のあいだの距離または月です。1回だけなら、そのギアの最初の走行日からその交換までです。その日より前の走行は入りません。積算のギア走行距離（例: 16,227 km）そのものではありません。

```
交換目安
┌ 推奨  6,000 km                    ┐  ← 名前から自動で決まります
└───────────────────────────────────┘
┌ 自動  4,800 km                    ┐  ← 直近の2回の間隔。毎回計算
└───────────────────────────────────┘
┌ 設定  5,000 km                    ┐  ← 自分で入力します
└───────────────────────────────────┘
```

詳細では分母の横に、今使っている方を出します。

```
4,800 / 6,000 km
80% · そろそろ     推奨 · しきい値 80%
```

## 表示のまとめ

ギア画面から開きます。内部の処理は登録名だけです。まとめた名前はホーム用の表示名で、登録名とは別です。差ができても合わせこみはしません。

**分けて表示**

まとめを解除し、2カードを登録名のまま出します。末尾に F/R を付ける改名はしません。

**まとめて表示**

登録名の違う2件を1カードにします。次の3つを指定します。

1. まとめる2つの部品（登録名で選ぶ）
2. どちらが F か（残りが R。左が R、右が F）
3. カードの表示名（例: タイヤ）

```
表示のまとめ

1. 2つの部品を選ぶ
   [前タイヤ]  [後タイヤ]

2. どちらが F か
   [ 前タイヤ が F ]

3. まとめた名前
   [ タイヤ ]

ホームは「タイヤ」。左が R、右が F
```

## Strava 連携

走行を追加の「Strava 連携」から開きます。連携方法の説明は「連携を解除」の下です。連携は任意です。説明は走行を追加の画面にあります。

```
戻る                    Strava 連携

未連携 / 連携済み
Strava 連携は任意です。          ← 未連携のとき
Client ID
Client Secret
[ 連携する ]
[ 連携を解除 ]

連携方法
1. Strava の API 設定でアプリを作る。Callback Domain は触らなくてよい
2. Client ID と Secret を上に入れる。このアプリでは Access Token は使いません
3. 「連携する」を押す。スマホでは許可するとアプリに戻る。パソコンでは Chrome が自動で開き、許可すると 127.0.0.1 に案内が出る。その画面を閉じることが必須。パソコンではアプリは手前に切り替わらない。連携ボタンが緑に戻り「連携済み」なら成功
4. Chrome が自動で開かないときだけ、許可用 URL をコピーして Chrome で開く
```

走行の追加はホームの「走行を追加」からです。連携画面では手順だけを書きます。Strava は任意です。

## ギアの選択

ホームのギア名（緑の枠ボタン）から開きます。自転車は手で足せます。Strava から取った自転車も同じ一覧に出ます。部品の走行距離は、選んだギアの走行だけを足します。交換記録と CSV も、選んだギアだけです。

ギア画面のいちばん上に、選んでいる自転車の名前を大きく出します。その下で自転車を選び、自転車を追加、自転車を削除、部品を追加、交換記録の CSV、部品登録の CSV、表示をまとめる / 分ける、を開きます。選ぶまでは CSV も交換記録も入力できません。部品の追加と設定の変更は、選んだギアにだけ効きます。初期の部品はどの自転車も同じです。

部品の最初の交換日は、そのギアのいちばん古い走行日です。走り始める前に部品を最新にしていた、という前提です。起点はその日の 0:00 なので、その日の距離も日数も入ります。

```
戻る                            ギア

ロード（デモ）                  ← 大きめ

距離を計算する自転車です。
```

## 走行を追加

ホームの「走行を追加」を押すと、この画面に切り替わります。起動時や裏での自動取得はしません。対象は、ホームで選んでいるギアです。手入力と Strava は同じギアでも混ぜてよいです。

デモのあいだは、上が手入力、下が Strava から取り込む、です。最初の実走行でデモ走行は消えます。そのあとも両方使えます。手入力の走行は「Strava から取得」とは書かず、連携済みにもしません。

```
戻る                    走行を追加

手入力
選んでいるギア: ロード
日付
[ 2026-09-03 ]
距離
[ 32 ] km
[ 記録する ]

[ 走行を確認 ]          ← 別画面。交換記録と同じ大きさの表。種類列あり

Strava から取り込む
連携は任意です。走行は手入力でも入れられます。
データの範囲
Strava開始日  2025-07-17
何日まで  2026-07-15
[ 前回から 1 年 ]     ← 未連携なら灰色
[ Strava開始日を変更 ]
[ Strava 連携 ]
```

走行を確認:

```
戻る                    このギアの走行
選んでいるギア: ロード
手入力の行をタップして日付・距離の修正や削除

日付          距離      種類
2025-08-01    15 km    Strava
2026-09-03    32 km    手入力     ← 手入力だけタップで下の欄
```

下段の「前回から 1 年」は、連携したときだけ押せます。未連携は灰色で、「Strava 連携」から開きます。連携の前後でボタンの数は同じです。Strava開始日を変えると、取り込んだ Strava は消えます。手入力は残ります。この操作では取得しません。「前回から 1 年」で新しい日から取り直します。

「前回から 1 年」は、取り終えた日（まだなければ Strava開始日）から先を足します。期間は 12 か月、今日までです。

候補として挙がっているが、まだ置かないもの:

- 取得の単位や失敗時のやり直し

詳細は [Strava 連携](Strava連携.md) に残します。

## 交換記録の CSV

ギア画面の「交換記録の CSV」から、選んだギアのいまの記録を書き出せます。取り込みも同じ画面です。上にギア名を大きく出します。ギアが決まっていないときは入力できません。登録名の一覧は出しません。CSV 欄の高さは固定で、中だけスクロールします。「例を入れる」は初期部品の登録名を全部出し、交換日はそのギアの最初の走行日です。空欄の交換日も同じです。交換日は `YYYY/MM/DD`（Excel と同じ）。以前の `YYYY-MM-DD` も取り込みます。部品は作りません。まとめ表示の名前ではなく登録名で結びます。CSV に出てきた登録名は、そのギアのいまの交換記録を消し、CSV の日付で差し替えます。他のギアの記録はそのままです。同じ CSV 内の同じ部品・同じ日だけ飛ばします。

「CSVを取り込み」を押すと、そのボタンを灰色にしてすぐ下に「確定」を出します。「確定」で取り込み、ボタンは再び緑になり「確定」は消えます。

```
登録名,交換日,メモ
前タイヤ,2025/03/01,パンク後に交換
後タイヤ,2025/08/01,サイドカット
```

## 部品登録の CSV

ギア画面の「部品登録の CSV」から、選んだギアの部品設定を書き出せます。取り込みも同じ画面です。操作は交換記録の CSV と同じです（書き出し、固定の CSV 欄、取り込み、確定）。

```
登録名,周期,目安,推奨の値,設定の値,しきい値,まとめ,位置
前タイヤ,距離,推奨,6000,5000,80,タイヤ,F
後タイヤ,距離,推奨,6000,5000,80,タイヤ,R
チェーン,距離,設定,4000,3500,70,,
```

無い登録名は部品を足します。最初の交換日は、そのギアのいちばん古い走行日です。CSV に出た部品の設定とまとめだけ差し替えます。交換記録と、CSV に無い部品はそのままです。並び順は出しません。
